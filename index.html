How It Works

Step 1 — Enter Email

User enters or pastes email content.

Step 2 — Text Preprocessing

Remove unnecessary characters, convert text to lowercase, remove stopwords, and clean the text.

Step 3 — Feature Extraction

Convert the email into numerical features using TF-IDF.

Step 4 — ML Prediction

The trained Machine Learning model predicts Spam or Not Spam.

Behind the Model

Python

Core language for training, the API and all glue code.

Pandas

Loads spam.csv, cleans labels and splits the data.

NumPy

Fast numeric arrays used under the hood by scikit-learn.

NLTK

Stopword removal and Porter stemming for text cleaning.

Scikit-learn

Model training, evaluation metrics and saving with Joblib.

TF-IDF

Scores words by how unique they are to spam vs. normal mail.

Naive Bayes / Logistic Regression

Both are trained; the one with the better F1 score is used.

Model Performance

Real values calculated on the held-out test set when the model was trained.

Dataset

The model is trained on a labeled dataset containing spam and legitimate email messages.

About Project

Spam Email Classifier is a Machine Learning project designed to automatically identify unwanted and potentially harmful email messages. The system uses Natural Language Processing and Machine Learning techniques to analyze email text and classify it as Spam or Not Spam.
